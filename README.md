# explorer-client

Euler Explorer frontend (React). Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/explorer-client-archive`.

**Stripped before publish:** TradingView Charting Library (`src/charting_library/`, `public/static/charting_library/`) — proprietary, not redistributable. Chart widgets in this tree will not run without your own licensed copy. A p2pify RPC URL was replaced with a public BSC testnet seed. The Sentry DSN was moved to `REACT_APP_SENTRY_DSN`. Demo JWT secret is a placeholder (`dev-key`).

No contract deployments recorded in this repo.

## What was Built

Euler Tools' blockchain explorer frontend application. Provided a web interface for searching and browsing blocks, transactions, addresses, and tokens on supported chains.

## Qué se Construyó

Aplicación frontend del explorador blockchain de Euler Tools. Proporcionó una interfaz web para buscar y explorar bloques, transacciones, direcciones y tokens en las cadenas admitidas.
